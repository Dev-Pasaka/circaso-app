# Demo profile photos: credits

Stock photos for the made-up people in Circaso's demo screens (`-preview=<name>` on iOS, `--es preview <name>` on
Android) and the store screenshots made from them. They are never shown to a real user: only the preview screens use
them, and those open in debug builds only. The files are Compose resources, so they are bundled in every build (about
350 KB) though nothing in a release build displays them. Downloaded 2026-11-12 from Unsplash, cropped square around the face and resized to 400 x 400 JPEG.
