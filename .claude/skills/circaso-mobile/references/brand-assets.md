## Vector sources in this repo
The SVG masters are in `assets/brand/` (mark, icon, black/white marks, logo). The app uses **vector drawables**, not bitmaps, so the mark is sharp at any size and costs about 3 KB instead of 360 KB. They are generated by `scripts/make_logo_vectors.py`, because the SVGs build the mark with an SVG mask that Android vector drawables cannot express: the script writes the mask out as real outlines. It produces the Compose resources `circaso_mark`, `circaso_mark_black`, `circaso_mark_white`, and the Android adaptive icon (white mark on `#0B0B0C`, plus a monochrome layer for themed icons). Rerun it if the master SVG changes. **The Android launch splash is the exception: it uses `circaso-mark-1024.png` (in `androidApp/src/main/res/drawable-nodpi/splash_mark.png`), because the system rasterises a gradient vector at low resolution on the splash and scales it up, which looked blurry on a real phone.** Not covered: the iOS app icon (needs an opaque 1024 px PNG, see the store caveat above) and the launcher PNGs for Android 7 (API 24 and 25), which are still the template's.

## How to use them in the app
- **Launcher icons:** Android adaptive icon from `circaso-icon.svg` (Android Studio Image Asset); iOS from the 1024 px PNG (opaque version, see caveat) in the Xcode asset catalog. The template launcher in `androidApp/src/main/res` and `iosApp/iosApp/Assets.xcassets/AppIcon.appiconset` is still the default.
- **In-app logo and Asha avatar:** prefer vector. Bundle the SVGs as Compose resources (convert to Android vector drawable XML for `composeResources/drawable`) instead of fetching them at runtime: the app must work offline and the logo must never flash empty. Pick black or white logo/mark by theme (`CircasoTheme.colors.isDark`).
- Never hotlink `assets.circaso.com` for anything shown on the first screen.
